# MAK4I Vision

## The Long-Term Vision

MAK4I enables portable AI memory across every model, platform, and organization.

Just as Git standardized source control and npm standardized package distribution,
MAK4I standardizes knowledge continuity for AI.

## Three Memory Types

MAK4I organizes knowledge into three distinct memory types,
each serving a different purpose.

### Procedural Memory — How
Knowledge describing how work is performed.

Examples:
- Coding frameworks and project templates
- API design standards and deployment pipelines
- Diagnostic workflows and testing strategies
- CI/CD processes and prompt templates
- Engineering playbooks

This memory rarely changes and can be reused across many projects.

### Semantic Memory — What
Knowledge describing what is true about a project or organization.

Examples:
- System architecture and API specifications
- Database schemas and domain models
- Product catalog and business glossary
- Security policies and compliance requirements
- Internal documentation and organization knowledge base

### Episodic Memory — Why
Knowledge describing what happened during a project.

Examples:
- Architecture decisions and design rationale
- Customer feedback and meeting outcomes
- Project milestones and feature discussions
- Bug investigations and sprint summaries
- Team conventions

## The Registry Model

Memory becomes a reusable dependency.

```bash
mak4i install company/backend-standards
mak4i install company/security-policies
mak4i install schedovia/context
mak4i inject
```

Instead of writing prompts, developers install knowledge.

## The Standards Process

MAK4I uses the **MAK-XXXX** convention for protocol standards.

```
MAK-0001  Artifact Metadata Schema
MAK-0002  Context Injection Specification
MAK-0003  Memory Resolution Algorithm
MAK-0004  Conflict Resolution Rules
MAK-0005  Versioning and Compatibility
```

Anyone can propose a new MAK standard via GitHub Pull Request.
Talvik reviews and stewards the process.

### Conformance

Every implementation can be tested against the MAK4I Conformance Suite.

```
MAK4I Certified
```

This badge signals that an implementation fully conforms to the protocol.
