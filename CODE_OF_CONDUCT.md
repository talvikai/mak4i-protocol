# Code of Conduct

MAK4I is an open project, developed in public. This document sets clear
expectations for anyone participating — in issues, pull requests,
discussions, or any other project space.

---

## Our Standard

We expect everyone participating in this project to:

- **Be respectful in all interactions.** Disagreement is normal and
  welcome; hostility is not.
- **Focus feedback on ideas, not people.** Critique the proposal, the
  code, or the argument — not the person making it.
- **Welcome contributors of all backgrounds and experience levels.** A
  question from someone new to the protocol deserves the same patience as
  one from a long-time contributor.
- **Acknowledge what others have built before proposing changes.** Read
  existing standards, discussions, and prior art before assuming
  something hasn't been considered.
- **Assume good faith.** Most misunderstandings in an open, asynchronous
  project come from missing context, not bad intent.

## Unacceptable Behavior

- Harassment, insults, or personal attacks, in any project space
- Discriminatory language or behavior, in any form
- Publishing others' private information without explicit permission
- Sustained disruption of discussions, issues, or pull requests
- Any conduct that would reasonably be considered inappropriate in a
  professional setting

## Scope

This applies to all MAK4I project spaces — GitHub issues, pull requests,
Discussions, and any other official communication channel — as well as
to anyone representing the project in public spaces (for example, when
using an official project email address or posting as a project
maintainer).

## Reporting

If you experience or witness unacceptable behavior, report it to
**hello@talvik.ai**. Reports are reviewed and handled as promptly as
possible. All reports are handled with discretion.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this
standard, and may take any action they deem appropriate in response to
behavior they consider inappropriate, threatening, offensive, or harmful —
including warning, temporary suspension, or permanent removal from
project spaces.
